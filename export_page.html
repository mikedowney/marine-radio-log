Content

A gated or failed message has no transcript at all, which is most of what the receiver logs on a quiet channel. Thresholds let through any row that has no recorded value — the same rule the log's own sliders use — so an old row with no readability score survives a readability floor rather than vanishing from a dataset without saying so.

The export reads the permanent history table, so it reaches every message ever recorded — not just the ones still in the live log — and carries the receive-chain and decoder columns the log page leaves out. Audio is a different matter: the WAV is gone long before the transcript is, so only rows whose audio still exists is a much smaller set than it looks.
